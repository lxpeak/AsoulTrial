# 一个魂的试炼

A-SOUL 题材的 2D 俯视角肉鸽割草射击。原生 Canvas 2D + ES Modules，**零依赖、零构建**。

在线玩：<https://www.asoulgame.fun>（桌面浏览器 + 键盘）

## 操作

| 键 | 作用 |
|---|---|
| `WASD` | 移动 |
| `方向键` | 射击方向（自动连射） |
| `空格` | 释放技能（技能条满时） |
| `ESC` | 暂停 |
| `1/2/3`，或 `← →` + `空格` | 升级三选一时选卡 |

## 内容

- **3 位角色**，技能各不相同：
  - 嘉然：追踪子弹，命中的小怪变糖果并爆炸
  - 贝拉：体型与速度提升，撞击秒杀小兵并掉星星
  - 乃琳：四向穿透攻击，命中冻结周围敌人
- **5 种敌人**（青蛙 / 疾行蛙 / 铁符蛙 / 精英符王 / Boss 符王·本相）：每 75 秒一只精英，每 150 秒一只 Boss
- **4 种道具**（治疗包 / 炸弹 / 护盾 / 荆棘）+ **12 张升级卡**，每局构筑都不同
- Boss 按血量切三阶段，越怒弹幕越密

## 开发

```bash
# 本地运行（也可以双击 dev.bat，会自动选 Node / Python）
node dev-server.mjs          # 然后打开 http://localhost:8000

# 测试（无浏览器，跑真实模块）
node test/smoke.mjs

# 截图验证（需要本机有 Edge/Chrome）
node tools/shot.mjs --url=http://127.0.0.1:8123 --steps=shots/x.json
```

调试参数：`?debug=1` 开调试面板（F1 跳波 / F2 升级 / F3 无敌 / F4 清屏），`?seed=12345` 复现某一局。
