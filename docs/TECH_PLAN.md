## 一、运行与开发

原生 Canvas 2D + ES Modules，**零依赖、零构建**。世界 1600×1200，视口 800×600，逻辑固定 60Hz。

| 事项 | 做法 |
|---|---|
| 本地运行 | 双击 `dev.bat`（有 Node 用 `dev-server.mjs`，否则用 Python ≥3.8），访问 `http://localhost:8000` |
| 为什么不能直接开 index.html | ES Module 走 `file://` 会被 CORS 拦掉，页面只会显示"加载失败" |
| 部署 | GitHub Pages，`CNAME` = `www.asoulgame.fun`。Pages 缓存顽固：改完代码线上没变就 `Ctrl+Shift+R`，或改 `?v=` |
| 测试 | `node test/smoke.mjs`（无浏览器，用最小 DOM/Canvas 桩跑真实模块）。当前 **312 项** |
| 截图验证 | `node tools/shot.mjs --url=http://127.0.0.1:8123 --steps=shots/x.json`；加 `--slow=1` 限速 6Mbps 复现弱网 |
| 调试 | `?debug=1` 开面板（F1 跳波 / F2 升级 / F3 无敌 / F4 清屏）；`?seed=12345` 固定随机种子 |
| 版本号 | `src/data/version.js` 是唯一真值，`index.html` 的 `<title>` 和 `?v=` 跟着改（测试会拦）。每轮迭代 +0.1 |

## 三、九条不变量（改代码前先看这一节）

### 1. 玩家锚点唯一真值是"脚底"
`p.y` = 脚底。碰撞盒、枪口位置、摄像机跟随点、阴影、UI 全部由它派生，**不要在别处再假设一个"中心"**。
派生常量集中在 `data/appearance.js`（`playerBox()` / `muzzleOf()` / `playerCenterY()`），按比例算而不是写死像素。

### 2. 碰撞盒 ≠ 受击盒
敌人的 40×40 底盘只负责**移动、接触、分离**；命中判定走 `enemyHurtBox(e)`，按渲染元数据推导（视觉 78~165 高）。
否则会重现"上半身打不到"。

### 3. 护体同一时刻只有一个
规则全在 `game/guard.js`。护盾 ⇄ 荆棘互相顶掉，开技能清掉两者；`guardKind()` 是唯一判定入口，
调用点只判断是不是 `null`。**技能护体期间捡到防御道具不吃，留在地上**（技能是攒来的，不能被道具降级）。

荆棘是"按次数消耗"：4 层耐久，**每挡一次给 1 秒无敌**，打光时三角立刻消失。
半径/命中半径/边长/伤害全部取 `guard.js` 里的常量，绘制端（`gameview`）和判定端（`update`）共用一份。

> 教训：技能护体曾经借 `p.invincible = 780`，而 `pose.js` 用 `invincible > 48` 判"刚被打到"，
> 结果整段 13 秒技能都在播受击姿势。**`p.invincible` 只表示挨打后的 1 秒无敌帧，不许塞别的语义。**

### 4. 伤害只有一个入口
`combat.js` 的 `damageEnemy()` / `damagePlayer()`。扣血 → 粒子 → 音效 → 移除 → 击杀数 → 充能 → 经验，
全在里面。暴击**在出膛时掷**并写进子弹，伤害入口保持纯函数（测试不会被随机数咬）。

### 5. 波次导演是纯函数
`director.js` 的 `tickDirector(gs, random)` 只返回"这一帧该刷什么"，不创建实体。随机数由参数注入 → 可单测、可复现。
Boss 优先级高于精英：撞车时精英**推迟 3 秒**（`ELITE_HOLD_AFTER_BOSS`），让位期结束后补上，节点不丢。

### 6. 加载闸门：撤加载层必须是最后一步
`读档 → 建输入 → 等图片 → 开循环 → 撤加载层`。`complete` 为真不等于成功（失败也是 complete），要看 `naturalWidth > 0`；
单张 12 秒超时；`onload` 后再 `decode()` 防首帧卡顿。

### 7. 画质：DPR 封顶 2，摄像机取整
`canvas.js` 里 `dpr = min(devicePixelRatio, 2)`，逻辑坐标仍是 800×600。摄像机 `Math.round`，否则整屏发虚。

### 8. 界面是栈，输入只给栈顶
`ui/screen.js`。`opaque: false` 的半透明界面（暂停/结算/三选一）会自动把下层战场画出来。
栈顶不处理就丢弃——不会出现"暂停时按空格还放技能"。

### 9. 存档必须能降级
无痕模式 / 配额写满 → `persistent = false`，只在内存里跑并提示；坏档当"没有存档"，绝不崩。

## 四、数值与节奏

### 难度阶段（`game/director.js` 的 `PHASES`，按存活秒数推进）

| 起 | 标签 | 刷怪间隔 | 同屏上限 | 血量系数 | 怪种权重 |
|---|---|---|---|---|---|
| 0s | 热身 | 78f | 14 | ×1.00 | 青蛙 |
| 50s | 试探 | 68f | 20 | ×1.05 | 青蛙3 疾行1 |
| 100s | 压迫 | 58f | 26 | ×1.20 | 青蛙3 疾行2 铁符1 |
| 160s | 混战 | 48f | 34 | ×1.40 | 青蛙2 疾行3 铁符2 |
| 240s | 狂潮 | 38f | 42 | ×1.70 | 青蛙2 疾行3 铁符3 |

最后阶段之后血量系数仍按 +0.2/分钟 继续涨，间隔继续收窄到 26f 下限——否则四分钟后卡组成型就一路推平。
**精英每 75 秒**（不占同屏上限），**Boss 每 150 秒**（场上只能一只）。

### Boss 三阶段（`data/boss.js`，按血量**比例**切，不看掉血量）

| 阶段 | 血量 | 齐射 | 夹角 | 弹速 | 间隔 | 血条色 |
|---|---|---|---|---|---|---|
| 本相 | 100~66% | 3 | 0.24 | 3.4 | 140f | 紫 |
| 本相·怒 | 66~33% | 5 | 0.19 | 3.9 | 118f | 品红 |
| 本相·狂怒 | ≤33% | 7 | 0.15 | 4.4 | 96f | 血红 |

只加密度不加新弹型：环形/追踪/激光每加一种都要重新教玩家怎么读。狂怒阶段多一轮补射，逼玩家躲完换个方向。

### 技能

- 充能：小怪 4、精英 15、Boss 30（25 杀攒满）。10 杀就满会让技能常驻，"攒大招"这件事消失。
- 演出：banner 3 秒（0.5s 滑入 + 1.5s 停留 + 1s 滑出），期间世界静止、玩家无敌；之后技能生效 10 秒。
- 斩杀只对**普通小怪**生效；精英/Boss 免疫，改按暴击结算（嘉然追踪弹、贝拉技能弹带 `exeCrit`，乃琳四向穿透不参与）。

### 道具与护体

| 道具 | 效果 |
|---|---|
| 治疗包 | +1 心 |
| 炸弹 | 全屏 5 点伤害 |
| 护盾 | 10 秒完全免伤，身上一圈蓝环 |
| 荆棘 | 5 秒内四个黄三角绕身旋转，碰到敌人造成 4 点伤害；自身 4 层耐久，**每挡一次给 1 秒无敌**，打完即碎 |

## 五、性能预算与实测

| 项 | 预算 | 实测（headless 软件光栅化） |
|---|---|---|
| 逻辑 `update()` | < 8ms/帧 | **1.8ms**（42 敌 + 20 弹） |
| 绘制 `drawScreens()` | < 8ms/帧 | **1.0ms** |
| 首屏体积 | — | 当前 **7.5MB**（背景 3.86 + 序列帧 3.64），压缩方案见 BACKLOG E1 |

结论：**性能不是当前瓶颈**。`enemyHurtBox` 每帧多次小对象分配、`Math.hypot` 的调用量都是理论问题，
不要为了跑分去改热路径。

## 六、素材管线（角色/敌人序列帧）

| 环节 | 做法 | 坑 |
|---|---|---|
| 出图 | AI 生成 4×2 = 8 格的 Q 版序列帧（384×512/格） | 所谓"透明底"实际是 RGB 棋盘格，必须自己抠 |
| 抠底 | `tools/sprite-sheet.mjs`：四边泛洪 + "无彩色且够亮"判定 | 只看颜色会误伤围裙/眼白；暖色描边用 `--warm-key` |
| 脚底线 | 逐格包围盒，底部对齐 + 水平居中，**只平移** | 模型每格构图随手定，不齐会一颠一颠 |
| 降采样 | `tools/sheet-shrink.mjs` 面积平均（先乘 alpha） | 直接 drawImage 缩小会出现半透明边缘发黑 |
| 登记 | `data/sprites.js` / `data/enemies.js` 的 `frameW/frameH/footPad` | 改图不改登记，测试里会炸 |
| 朝向 | 素材默认**朝左**，朝右才翻转（`facing: -1`） | 把"不翻转"当朝右会让左右移动反着 |
| 染色 | `gfx/tint.js` 离屏 `hue-rotate + saturate`，只算一次 | 每帧 filter 会掉帧 |

敌人共用一张青蛙帧表，靠体型（0.82/1.0/1.44/1.62）+ 色相（0/58/158/−84）区分——专属美术是 4 倍体积和 4 次生成。

## 七、已知限制

- **单机单存档**：`localStorage` 一个键，没有云同步/多档。
- **没有 BGM**，音效全部是 WebAudio 现场合成，技能人声是 3 个 `<audio>`。
- **没有地图变化**：一块 1600×1200 的空地 + 背景图。
- **一个 Boss、一种弹型**（只在发数/间隔上分阶段）。
- **素材是 A-SOUL 官方立绘与语音**：公开域名上线有被要求下架的风险。技术上能做的是把素材清单数据化，
  真出事时换图 10 分钟搞定。
